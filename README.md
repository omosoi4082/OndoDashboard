# 온도 스마트 축사(돈사) 시뮬레이션 대시보드

제주 돈사의 센서·기상 데이터를 받아 자돈방 내부 환경을 3D로 보여주는 대시보드입니다.
이 PC 한 대에서 화면과 중계 서버가 함께 돌아갑니다.

> **처음 받으신 분은 아래 "빠른 시작"만 따라 하시면 됩니다.** 5분이면 끝납니다.
> 설치가 끝나면 `테스트-체크리스트.md`를 열어 순서대로 확인해 주세요.

---

## 빠른 시작 (3단계)

### 0단계. Node.js 설치 (처음 한 번만)

이 프로그램은 Node.js가 있어야 돌아갑니다. 이미 설치돼 있으면 건너뛰세요.

1. <https://nodejs.org> 접속
2. **LTS** 라고 적힌 왼쪽 버튼을 눌러 내려받기
3. 내려받은 파일을 실행하고 **계속 "다음"**만 누르면 됩니다 (설정 바꿀 것 없음)
4. 설치가 끝나면 **컴퓨터를 한 번 다시 시작**해 주세요

> 설치됐는지 확인하려면: 시작 메뉴에서 `cmd` 실행 → `node -v` 입력 → `v20.x.x` 같은 게 나오면 정상

### 1단계. 압축 풀기

받으신 압축 파일을 **한글·공백이 없는 경로**에 푸세요. 예: `C:\ondo\`

> `바탕 화면`이나 `다운로드` 폴더에서 바로 실행하면 가끔 경로 문제로 실패합니다.

폴더 안에 `start.bat`, `check.bat` 같은 파일이 보이면 제대로 풀린 것입니다.

### 2단계. 실행

**`start.bat`** 을 두 번 클릭하세요.

- 검은 창이 뜨고 잠시 뒤 **브라우저가 자동으로 열립니다**
- 안 열리면 브라우저에 직접 입력: **<http://localhost:8080>**
- **검은 창은 닫지 마세요.** 이 창이 서버입니다. 닫으면 화면도 멈춥니다.
- 끝낼 때는 검은 창을 닫으면 됩니다

### 3단계. 상태 점검

**`check.bat`** 을 두 번 클릭하세요. (`start.bat` 창은 켜 둔 채로)

센서 서버·기상청·연산 서버 연결을 하나씩 확인해서 `✅` / `❌` 로 보여줍니다.
`❌` 가 나오면 **원인과 조치 방법이 바로 아래에 같이 나옵니다.**

결과는 `점검결과.txt` 파일로도 저장되니, 문제가 있으면 그 파일을 보내 주시면 됩니다.

## 설정 바꾸기 — `setup.bat`

기상청 키나 **연산 서버 주소**를 넣거나 바꿀 때 씁니다. `.env` 파일을 직접 열 필요 없습니다.

**`setup.bat`** 을 두 번 클릭하면 세 가지를 차례로 물어봅니다.
**바꾸지 않을 값은 그냥 엔터**를 치면 기존 값이 유지됩니다.

| 묻는 것 | 설명 |
|---|---|
| 기상청 서비스키 | 이미 들어 있습니다. 바꿀 일 없으면 엔터 |
| 연산 서버 모드 / 주소 | **연산 서버 주소를 받으셨을 때 여기에 넣습니다** (아래 참고) |
| 센서 서버 모드 / 주소 | 실제 센서를 쓰면 `live`. 보통 그대로 두시면 됩니다 |

설정을 바꾼 뒤에는 **`start.bat`을 다시 실행**해야 반영됩니다.
(이전 설정은 `.env.bak` 파일로 자동 백업됩니다.)

### 연산 서버 주소를 받으셨다면

처음 전달본은 연산 서버 없이도 화면이 전부 뜨도록 **목업(mock) 모드**로 설정돼 있습니다.
실제 연산 서버를 연결하려면:

1. `setup.bat` 실행
2. 기상청 키는 엔터로 넘기기
3. 연산 서버 모드에 **`http`** 입력
4. 주소 입력 — 예: `http://192.168.0.21:9000` (같은 PC면 `http://localhost:9000`)
5. 센서 서버는 엔터로 넘기기
6. `start.bat` 다시 실행 → `check.bat` 으로 확인

> 목업 모드일 때는 `check.bat` 에 "연산 서버가 mock 모드입니다 — 실제 연산 결과가 아닙니다"
> 라는 `⚠️` 안내가 나옵니다. 정상이며, 화면 동작을 확인하는 데는 문제가 없습니다.

## 안 될 때

| 증상 | 해결 |
|---|---|
| `start.bat` 을 눌러도 창이 깜빡이고 사라짐 | Node.js가 설치되지 않았습니다. 0단계를 다시 해 주세요 |
| "설정 파일(.env)이 없습니다" | `setup.bat` 을 먼저 실행하세요 |
| "라이브러리가 설치되어 있지 않습니다" | `install.bat` 을 먼저 실행하세요 (인터넷 필요, 몇 분 걸림) |
| 브라우저에 아무것도 안 나옴 | `start.bat` 창이 켜져 있는지 확인하고, 주소가 `http://localhost:8080` 인지 확인 |
| 화면은 뜨는데 값이 `-` 로 비어 있음 | `check.bat` 을 실행하면 어느 연결이 끊겼는지 알려줍니다 |
| 그래도 안 됨 | `check.bat` 실행 후 생기는 `점검결과.txt` 를 담당자에게 보내 주세요 |

**어떤 문제든 먼저 `check.bat` 을 실행해 보세요.** 대부분 원인과 조치가 바로 나옵니다.

## 지원 환경

- **Windows 10 / 11**
- **Chrome 또는 Edge 최신 버전** (Internet Explorer는 지원하지 않습니다)
- 화면 해상도 **1920 × 1080 기준** — 모바일·태블릿은 지원하지 않습니다
- 센서 서버·연산 서버와 **같은 네트워크(공유기)** 에 있어야 합니다
- 기상청 조회를 위해 **인터넷 연결**이 필요합니다

구조·명세·작업 단계는 `docs/` 아래에 있습니다.

|---|---|

| `docs/02-relay-api.md` | 대시보드 ↔ 중계 서버 API 계약 + TypeScript 타입 |
| `docs/03-upstream-apis.md` | 중계 서버 → 센서 서버·기상청·연산 서버 연동 규칙 |
| `docs/04-tasks.md` | 단계별 작업 목록과 완료 조건 |

| `docs/08-development.md` | 개발 환경 구동, 에이전트 사용법, 진행 순서 |

```
npm install            # 의존성 설치
npm run dev            # relay(8080) + dashboard(5173) 동시 실행 (개발)
npm run build          # shared → relay → dashboard 순서로 빌드
npm start              # 운영 모드 — 단일 포트 8080
npm run doctor         # 상태 점검 (check.bat과 같음)
npm run setup          # 설정 입력 (setup.bat과 같음)
npm test               # vitest
npm run typecheck      # 타입 검사
npm run lint           # eslint + oxlint
```
