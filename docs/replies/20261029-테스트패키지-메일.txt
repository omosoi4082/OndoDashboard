■ 실행 방법

1. 한글과 공백이 없는 경로에 압축을 풀어 주세요. (예: C:\ondo\)
2. start.bat 을 더블클릭하고, 뜬 검은 창은 닫지 말아 주세요.
3. 브라우저에서 http://localhost:8080 을 엽니다.
4. check.bat 을 더블클릭합니다. (연결 점검 7단계, 1~2분)
5. test-ui.bat 을 더블클릭합니다. (화면 자동 점검 65개, 약 2분 20초)
6. 같이 들어 있는 "테스트-체크리스트.md" 를 위에서부터 따라가며 봐 주세요.

보내 주실 것: 화면점검결과.txt / ui-test-results 폴더 / 체크리스트


■ 이번에 달라진 것

체크리스트 맨 앞에 "이번 패키지에서 달라진 것" 표로 정리해 두었습니다.
크게 일곱 가지입니다.

1. 분석 항목이 온도 / 습도 두 개가 되었습니다. 유동 버튼은 없앴고,
   네 모드 모두 공기 입자를 늘 보여 주며 입자 색이 고른 항목을 따릅니다.
2. 화면을 열면 방 전체에 입자가 있습니다. 새 입자는 급기구에서 나오고,
   멈춘 입자는 방 안 다른 곳에서 다시 출발합니다.
3. 입자가 배기구 앞에서 원 중심으로 빨려 들어가 사라집니다.
   배기구 팬 모델도 키워서 벽에 붙였습니다.
4. 2D 수평단면이 3D 화면 안 오른쪽 아래로 들어갔고, 색 범례는 하나입니다.
5. 단면 높이 슬라이더가 생겼습니다. (0.1 ~ 2.7 m)
6. 배속(1·3·10배)이 입자와 타임라인에 함께 걸립니다.
   현재 모드는 한 시각만 보여 주므로 배속 버튼이 없고 늘 1배입니다.
7. 상세 패널이 넓어졌고, 네 모드의 3D 크기와 원근이 같아졌습니다.

전문가·제어 모드는 말씀하신 대로 목업 그대로 두었습니다.


■ 가시화 데이터(viz)를 켜서 보냅니다

"사무실 연산 서버는 v1.3.3으로 업데이트했고 v1.3.2도 viz를 무시하니 미리 넣어
두셔도 괜찮다"고 하셔서, 기본 켜짐으로 설정했습니다.
연산 서버 주소도 http://192.168.10.91:9000 으로 미리 넣어 두었습니다.

켜짐이면 입자가 2,584점 정밀 유속을 따라 흐릅니다.
꺼짐이면 기존 288점으로 그려서 급기구 바로 아래 기류가 뭉개집니다.

끄고 켜는 법: setup.bat 실행 → [2/3] 연산 서버 → "가시화 데이터" 물음에 on / off
→ 바꾼 뒤 start.bat 다시 실행
지금 상태는 check.bat 의 [1/7] 마지막 줄에 나옵니다.


■ 화면 해상도 안내

화면은 창 크기에 맞춰 반응형으로 배치됩니다. 헤더, 외부환경 정보, 상세 패널이
창 크기에 맞춰 늘고 줄며, 가로·세로 스크롤바가 생기지 않습니다.
오른쪽 상세 패널의 3D 영역도 창 높이에 따라 같이 커지고 작아지며, 네 모드의
모델 크기와 보는 각도는 항상 같게 유지됩니다.

다만 왼쪽 메인 화면의 축사 3D 모델은 1920 x 1080 기준으로 고정돼 있습니다.
창이 그보다 작으면 축사의 일부가 화면 밖으로 잘립니다.
1920 x 1080 해상도에서 브라우저를 전체화면(F11)으로 두고 봐 주시면
설계한 그대로 보입니다. 그보다 큰 화면은 문제없습니다.
