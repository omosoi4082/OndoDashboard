## 이번 패키지에서 달라진 것 (10/22 패키지 대비)

체크리스트 머리말 "이번 패키지에서 달라진 것" 표와 같다.

1. 분석 항목이 **온도 / 습도** 두 개(유동 삭제). 네 모드 모두 유동 입자를 늘 보여 주고 입자 색이 그 항목을 따른다 — 10/28 회신 1번.
2. **화면을 열면 방 전체에 입자가 있다.** 새 입자는 급기구에서, 멈춘 입자는 방 안 다른 곳에서 다시 출발 — 10/28 회신 2번("일정 시간 멈춰 있으면 다시 출발시키는 정도면 충분").
3. **배기구**: 입자가 배기구 앞에서 원 중심으로 빨려 들어가 사라진다. 쏠림은 y = 0 벽에 닿은 입자에만 적용(회신 2번 확인 요청 — 이미 그랬다). 배기구 팬 모델도 키워서 벽에 붙였다.
4. **2D 수평단면이 3D 화면 안 오른쪽 아래**로, **색 범례는 하나** — 회신 1번.
5. **단면 높이 슬라이더** 추가(0.1~2.7 m).
6. **배속(1·3·10배)이 입자와 타임라인에 함께** 걸린다. **현재 모드에는 배속 버튼이 없다**(한 시각만 보여 주므로 늘 1배).
7. 상세 패널 788 → **840 px**, 네 모드의 3D 크기·원근이 같아졌다.
8. 제어 모드에서 **에너지 ↔ 환경**을 바꾸면 분석 항목·배속·단면 높이가 기본값으로 돌아간다.
9. 전문가·제어는 **목업 그대로** — 10/28 회신 3번.
