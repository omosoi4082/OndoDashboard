## ■ 1. 유동을 볼 때 2D 수평단면

말씀하신 대로 3D와 2D의 범례가 다르면 보시는 분들이 많이 헷갈릴 것 같습니다. 그래서 죄송하지만,
가·나안 대신 화면 구성을 조금 바꿔 주실 수 있을지 조심스럽게 여쭙니다.

- 지금: 온도 / 유동 / 습도
- 부탁드리는 구성: 온도 / 습도 (유동 선택지는 없애고, 두 화면 모두 입자를 보여 줌)
  - 온도: 3D 입자(색 = 온도) + 2D 수평단면(온도)
  - 습도: 3D 입자(색 = 상대습도) + 2D 수평단면(습도)
- 한 화면 안에서 3D 입자와 2D 단면이 같은 색 범위를 쓰면 범례 하나로 둘 다 읽을 수 있을 것 같습니다.
- 현재·예측·전문가·제어 모드 모두 같은 구성이면 좋겠습니다.

2D 유속 화면은 없어지지만, 방 안 유속은 같은 높이에서 거의 차이가 없어(대부분 0.01~0.07 m/s 안)
단면 색이 거의 한 가지로 나옵니다. 그래서 빼도 괜찮다고 판단했습니다. 공기 흐름은 입자 움직임으로 보입니다.
필요한 값은 지금 응답의 grid.temp, grid.rh, grid.flow에 모두 있어서 따로 보내드릴 데이터는 없습니다.

납품을 이틀 앞두고 드리는 무리한 부탁인 줄 압니다. 일정상 어려우시면 지금 구성(온도/유동/습도)을
유지하고 나안(2D도 입자 색과 같은 값)으로만 해 주셔도 괜찮습니다. 편하신 쪽으로 말씀해 주세요.

## ■ 2. 배기구 처리

배기구로 모이게 해 주신 방식 좋습니다. 한 가지만 확인 부탁드립니다. 벽면을 따라 배기구로 모이는
움직임은 배기구가 있는 벽(y = 0)에 닿은 입자에만 적용되고 있을까요?
바닥·천장·다른 벽에 붙은 입자까지 배기구로 미끄러지면 실제보다 빠른 바닥 기류처럼 보일 수 있어서요.
그런 입자는 일정 시간 멈춰 있으면 다시 출발시키는 정도면 충분합니다. 이미 그렇게 되어 있다면
그대로 두셔도 됩니다.
