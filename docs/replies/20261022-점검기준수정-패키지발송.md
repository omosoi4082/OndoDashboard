# 4차 회신 — 점검 기준 수정 패키지 발송 (2026-10-22 목)

10/22 온도 측 점검에서 유일하게 실패한 B-2-10(2D 수평단면)이 **점검 기준 문제**로 확정돼
(`20261022-화면점검결과-회신.md`) 고친 뒤, 그 수정을 담은 패키지를 다시 보낸다.
사용자 지시: "우리 테스트 체크리스트는 이러했고 전부 통과 확인했다, 이제 온도에서 실행해 보시고
이상 있으면 알려 달라"로 보내고 **소스본과 빌드 포함본을 같이 준다.**

  표시, "2D 단면이 한 색으로 보이는 것은 정상" 항목.

## 메일 본문

> 안녕하세요. 보내 주신 점검 결과 확인하고, 고친 패키지 보내드립니다.
>
> **1. 지난 점검 결과 — 한 건만 저희 쪽 문제였습니다**
>
> - 상태 점검(`check.bat`) 7단계: **모두 정상**. 센서 서버·기상청·연산 서버 연결과
>   네 모드(현재·예측·전문가·제어) 데이터 모두 이상 없었습니다.
> - 화면 점검(`test-ui.bat`) 58개: **정상 56 / 확인 필요 1 / 건너뜀 1**
>   - 확인 필요였던 **B-2-10(2D 수평단면)** 은 화면이 아니라 **점검 기준**의 문제였습니다.
>     보내 주신 숫자(단면 최저 19.79℃ / 최고 19.90℃)로 확인했듯이 그 높이 온도가 고르게 나와
>     단면이 한 색으로 칠해진 것이고, 자동 점검이 그것을 "빈 화면"으로 잘못 판정했습니다.
>     **판정 방법을 고쳤습니다.**
>   - 건너뜀이었던 **B-6-2(10분 자동 갱신)** 은 보내 주신 확인(풍향이 바뀜)으로 **정상 확인**됐습니다.
>
> **2. 저희 쪽에서 체크리스트 전부 다시 돌렸습니다 — 전 항목 통과**
>
> 고친 뒤 저희 PC에서 처음부터 다시 확인했습니다.
>
> - 상태 점검 7단계 **전부 정상**
> - 화면 점검 58개 중 **정상 57 / 실패 0 / 건너뜀 1**
>   (건너뜀은 10분을 기다려야 하는 B-6-2 한 건이고, 이미 확인해 주신 항목입니다)
> - 연산 서버가 꺼져 있는 상황도 일부러 만들어 봤습니다. 그때는 "예측 서버 연결 안 됨"이라는
>   안내 한 가지만 나오고, 센서·기상청·화면은 그대로 동작합니다.
>
> **3. 보내드리는 것**
>
> 두 가지를 같이 보냅니다. **어느 쪽이든 하나만 쓰시면 됩니다.**
>
> - **`ondo-dashboard-20261022-점검기준수정.zip`** (19.7 MB) — 빌드까지 끝낸 것입니다.
>   압축을 풀고 **`start.bat`** 만 두 번 클릭하면 됩니다. **이쪽을 권합니다.**
> - **`ondo-dashboard-20261022-점검기준수정-src.zip`** (8.8 MB) — 소스입니다.
>   **`install.bat`** 을 먼저 두 번 클릭해 설치·빌드한 뒤(인터넷 필요, 몇 분) 같은 순서로
>   진행하시면 됩니다. 소스를 보관하거나 직접 빌드해 보실 때 쓰시면 됩니다.
>
> 연산 서버 주소(`http://192.168.10.91:9000`)는 **미리 넣어 두었습니다.** 압축은 한글과 공백이
> 없는 경로(예: `C:\ondo\`)에 풀어 주세요.
>
> **4. 실행 순서는 지난번과 같습니다**
>
> 1. **`start.bat`** — 서버가 뜨고 브라우저가 열립니다(검은 창은 닫지 마세요).
> 2. **`check.bat`** — 상태 점검. `점검결과.txt` 가 생깁니다.

> - **★3** 예측 모드 **재생이 부드러운지**(뚝뚝 끊기지 않는지)

> 같이). 폴더를 통째로 압축해 보내 주셔도 괜찮습니다.
