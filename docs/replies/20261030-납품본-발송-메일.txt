3. 10/29 화면 점검에서 나온 예측 모드 실패 7건

보내 주신 기록으로는 7건 모두 같은 증상이었습니다.
예측 모드 요청이 9~19초 만에 끊기고 "예측 서버 연결 안 됨"이 떴습니다.

- 저희 쪽 시간 제한(60초)에 걸린 것이 아니고, 같은 시간대에 정상으로 받은 요청도
  섞여 있어서 서버가 꺼져 있던 상황은 아니었습니다.
- 대시보드와 중계 서버 쪽에서는 같은 증상을 만들 만한 것을 찾지 못했습니다.
  그래서 이 부분은 코드를 바꾸지 않고 그대로 보내드립니다.

같은 증상이 다시 나오면 아래 두 가지만 보내 주시면 원인을 좁힐 수 있습니다.

- start.bat 검은 창의 내용 (그 시각 앞뒤로 "[compute] 연결 실패: ..." 줄이 찍힙니다)
- check.bat 을 눌러 생기는 점검결과.txt

그리고 예측 모드만 유독 느리거나 자주 끊기면, 폴더의 setup.bat 을 열어
[2/3] 연산 서버 의 마지막 "가시화 데이터" 를 off 로 바꿔서 한번 보셔도 됩니다.
입자가 따르는 유속이 2,584점에서 288점으로 바뀌어 주고받는 데이터가 크게 줄어듭니다.
(화면은 그대로 동작하고, 급기구 아래 기류만 조금 뭉개져 보입니다)


4. 10/26, 10/28 요청 반영

- 분석 항목이 온도 / 습도 두 개입니다. 유동 선택지는 없앴습니다.
  네 모드 모두 공기 흐름을 입자로 늘 보여 주고, 입자 색이 선택한 항목(온도 또는 습도)을
  따라갑니다. 3D와 2D가 같은 색 범위를 쓰므로 범례는 하나입니다.
- 화면을 열면 방 전체에 입자가 있습니다. 새 입자는 급기구에서 나오고,
  오래 멈춰 있던 입자는 방 안 다른 곳에서 다시 출발합니다.
- 배기구 앞에 들어온 입자는 배기구 중심으로 빨려 들어가 사라집니다.
  벽을 따라 모이는 움직임은 배기구가 있는 벽에 닿은 입자에만 적용됩니다.
- 2D 수평단면이 3D 화면 안 오른쪽 아래로 들어갔습니다.
- 단면 높이 슬라이더(0.1 ~ 2.7 m)가 생겼습니다. 끌면 3D에 그 높이 테두리가 보입니다.
- 배속(1 / 3 / 10배)이 입자와 타임라인에 함께 걸립니다.
  현재 모드에는 배속 버튼이 없습니다. 한 시각만 보여 주므로 늘 1배입니다.
- 상세 패널이 조금 넓어졌고, 네 모드의 3D 크기와 원근이 같아졌습니다.
- 제어 모드에서 에너지 와 환경 을 바꾸면 분석 항목, 배속, 단면 높이가 기본값으로 돌아갑니다.
- 전문가 모드와 제어 모드는 지난번과 같은 목업 파일로 동작합니다. (10/28 회신 3번)


5. 보내기 직전에 더 고친 것 세 가지

- 전문가 모드에서 필수값 수정 으로 들어갔다가 적용하지 않고 < 로 돌아올 때,
  분석 항목, 배속, 단면 높이, 타임라인이 그대로 남아 있었습니다.
  결과 화면을 다시 여는 것이므로 처음 들어왔을 때와 같은 상태로 돌아가게 했습니다.
  적용 을 눌러 들어갈 때도 같습니다.

- 배속을 10배로 한참 돌린 뒤 1배로 내리면 입자가 눈에 띄게 적어 보였습니다.
  입자 수가 급기와 배기의 균형으로 정해지는데 배기 쪽이 조금 더 많이 빠져서,
  배속이 높을수록 그 차이가 빨리 드러나던 것입니다.
  이제 1배, 3배, 10배 어느 쪽이든 방이 같은 정도로 차 있습니다.

- 화면 오른쪽 위 날짜와 시각의 글자 크기를 조금 줄였습니다.
