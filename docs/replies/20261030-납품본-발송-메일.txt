- ondo-dashboard-납품-20261030.zip (17.5 MB)
  빌드까지 끝낸 실행본입니다. 이것만 쓰시면 됩니다.

- ondo-dashboard-납품-20261030-src.zip (10.6 MB)
  소스입니다. 보관용입니다.


2. 쓰는 법

1) Node.js LTS 설치 (https://nodejs.org 에서 LTS 버튼, 설치 후 PC 재시작)
2) 압축을 한글과 공백이 없는 경로에 풀기. 예: C:\ondo
3) start.bat 두 번 클릭

브라우저가 저절로 열립니다. 안 열리면 http://localhost:8080 을 넣으시면 됩니다.
검은 창은 닫지 마세요. 그 창이 서버입니다. 끝내실 때 닫으면 됩니다.

화면 값은 10분마다 자동으로 갱신됩니다.
연산 서버 주소(http://192.168.10.91:9000)는 미리 넣어 두었으니 설정하실 것은 없습니다.


3. 안 될 때

check.bat 을 두 번 클릭하면 센서 서버, 기상청, 연산 서버 연결을 하나씩 확인해
원인과 조치 방법을 알려 주고 점검결과.txt 로 저장됩니다. 그 파일을 보내 주시면 됩니다.


4. 기상청 서비스키

지금 키는 저희 명의로 발급받은 것이고 2028-10-09 까지입니다.
당장 하실 일은 없고, 그 전에 온도 측 명의로 바꾸실 때는 setup.bat 의
[1/3] 기상청 서비스키 에 새 키를 넣으시면 됩니다.
