1. 보내드리는 것

- ondo-dashboard-납품-20261030.zip (17.5 MB)
  빌드까지 끝낸 실행본입니다. 이것만 쓰시면 됩니다.

- ondo-dashboard-납품-20261030-src.zip (10.7 MB)
  소스입니다. 보관용입니다.


2. 쓰는 법

1) Node.js LTS 설치 (https://nodejs.org 에서 LTS 버튼, 설치 후 PC 재시작)
2) 압축을 한글과 공백이 없는 경로에 풀기. 예: C:\ondo
3) start.bat 두 번 클릭

브라우저가 저절로 열립니다. 안 열리면 http://localhost:8080 을 넣으시면 됩니다.
검은 창은 닫지 마세요. 그 창이 서버입니다. 끝내실 때 닫으면 됩니다.

화면 값은 10분마다 자동으로 갱신됩니다.
연산 서버 주소(http://192.168.10.91:9000)는 미리 넣어 두었으니 설정하실 것은 없습니다.


3. 오늘 보내 주신 점검 결과

보내 주신 결과 잘 받았습니다. 서버 점검은 7개 항목 모두 정상이었고,
화면 점검은 63개 정상 / 1개 실패였습니다.

실패한 B-3-12(배속을 올리면 타임라인도 빨리 넘어간다)는 저희 쪽 문제가 맞았습니다.
고쳐서 이번 파일에 넣었습니다. 화면 그리는 속도가 재생을 따라가지 못하면 10배로 올려도
3배 정도까지밖에 안 빨라지던 것인데, 이제 PC가 느려도 배속대로 넘어갑니다.
값이나 계산과는 상관없고 보기 속도만의 문제였습니다.

같은 조건으로 저희 쪽에서 다시 돌려 화면 점검 65개 전부 정상인 것을 확인했습니다
(10분 기다려야 하는 자동 갱신 항목 1개는 자동 점검에서 빠집니다).


4. 안 될 때

check.bat 을 두 번 클릭하면 센서 서버, 기상청, 연산 서버 연결을 하나씩 확인해
원인과 조치 방법을 알려 주고 점검결과.txt 로 저장됩니다. 그 파일을 보내 주시면 됩니다.
