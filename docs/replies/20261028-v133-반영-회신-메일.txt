반영한 내용을 알려드리고, 확인이 필요한 두 가지를 여쭙니다.


1. 반영한 내용

- grid.flow(2,584점)가 오면 그것으로 입자를 움직이고, 없으면 기존 flow(288점)로 움직입니다.
- supply(급기 풍량)로 급기구에서 나오는 입자 개수를 정합니다.
- 받은 데이터를 쓰는 기능(viz)은 기본으로 꺼 두었습니다. 사무실 연산 서버가 v1.3.3으로
  올라간 뒤에 아래 순서로 켜 주시면 됩니다.
    setup.bat 실행 → [2/3] 연산 서버에서 http 선택 → 주소 확인 →
    "가시화 데이터" 질문에 on 입력
  check.bat과 start.bat 창에 "가시화 데이터(viz): 켜짐"으로 표시되면 적용된 것입니다.
- 실제 예측 응답의 forecast_issued_at이 null이라 저희 쪽 형식 검사에서 막히던 것을
  고쳤습니다. 서버 쪽에서 바꾸실 것은 없습니다.
- 2D 단면은 말씀하신 대로 실제 비율(4.5 x 4 m)을 유지합니다.


2. 입자 표현 — 보내 주신 데이터와 안내문 기준으로 만들었습니다

- 급기구 사각형 안 천장 바로 아래에서만 출발합니다. 개수는 supply.airflow_m3h에 비례합니다.
- 배기구에 닿으면 사라집니다(아래 질문 참고).
- 유속·온도·습도는 격자 8점 삼선형 보간입니다.
- 실제 속도의 1·3·10배를 화면에서 고를 수 있습니다(기본 10배 — 방 안 유속이 평균
  0.02 m/s라 낮은 배속에서는 거의 멈춰 보입니다).
- 재생과 함께 움직입니다. 일시정지하면 입자도 멈추고, 모드에 들어가거나 분석 항목
  (온도/유동/습도)을 바꾸거나 초기화를 누르면 빈 방에서 급기구부터 다시 시작합니다.
  보내 주신 샘플 뷰어와 같은 방식입니다.

안내문에 없어 저희가 정한 값은 동시에 떠 있는 최대 입자 수(4,000개), 꼬리 길이, 점 크기
(화면에서 1.5~7 px — 샘플 뷰어와 같은 방식입니다), 그리고 20초마다 급기구에서 다시
내보내는 것입니다. 마지막 항목은 입자가 한곳에 겹쳐 쌓여 화면이 비어 보이는 것을 막기
위한 것입니다.


3. 칸막이(Y자 가벽) 처리 — 저희 판단으로 넣었습니다. 아니면 되돌리겠습니다

보내 주신 유속 데이터에는 칸막이가 들어 있지 않습니다. 그래서 데이터대로만 움직이면
입자가 3D 화면의 칸막이를 그대로 통과합니다. 실제로 벽이 있는데 통과하는 그림이
어색해서, 화면에서만 다음과 같이 처리했습니다.

- 칸막이 높이(geometry.json의 0.78 m) 아래에서는 칸막이를 지나지 못합니다.
- 벽에 부딪친 기류는 벽면을 따라 흐르다가 위로 올라가 칸막이를 넘어갑니다.
- 칸막이 판 두께(모델 실측 4 cm) 안으로도 들어가지 않습니다.

연산 결과를 바꾸는 것이 아니라 입자의 움직임만 그렇게 그리는 것입니다.
혹시 칸막이가 유속 계산에 이미 들어가 있거나, 데이터 그대로 보여주는 편이 맞다고
하시면 설정 한 줄로 되돌릴 수 있으니 알려 주십시오.


4. 확인 부탁드립니다

(1) 배기구 판정 범위

안내문대로 배기구 원(지름 0.4 m) 안에 닿을 때만 지웠더니, 입자 대부분이 원 바로 바깥
벽에 붙었습니다. grid.flow에서 배기구가 (2.25, 0, 1.6) 한 점이고 둘레 벽 점은 0이라,
보간하면 원 밖에서는 벽 쪽 속도가 0으로 줄어들기 때문입니다.
그래서 지우는 범위를 "배기구 격자점이 걸친 격자 한 칸"(x 2.0~2.5 m, z 1.2~2.0 m,
벽에서 0.25 m 안)으로 넓혔습니다. 화면에 그리는 배기구 크기는 지름 0.4 m 그대로입니다.
참고로 보내 주신 샘플 뷰어는 배기구가 있는 벽 전체에 닿으면 지우고 있었습니다.
자돈방은 어느 쪽이 맞을지(원 / 격자 한 칸 / 벽 전체) 알려 주십시오.

(2) 유동을 볼 때 2D 수평단면의 기준

지금은 분석 항목을 따라갑니다 — 유동을 고르면 단면도 유속(m/s)으로 그립니다.
그런데 입자 색은 온도 또는 습도라서, 한 화면에서 3D 범례(℃ 또는 %)와 2D 범례(m/s)가
서로 다른 값을 가리킵니다. 셋 중 어느 쪽이 좋을지 알려 주십시오.
  가. 지금처럼 2D는 유속 단면으로 둔다
  나. 2D도 입자 색과 같은 기준(온도 또는 습도)으로 바꾼다
  다. 2D에 유속/온도/습도 전환 버튼을 따로 둔다
