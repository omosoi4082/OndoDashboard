1. 유동을 볼 때 2D 수평단면은 어느 값으로 그릴까요

지금은 유동을 고르면 단면도 유속(m/s)으로 그립니다. 그런데 3D 입자 색은 온도 또는 습도라서
3D 범례와 2D 범례가 서로 다른 값을 가리킵니다.
  가. 지금처럼 2D는 유속으로
  나. 2D도 입자 색과 같은 값(온도 또는 습도)으로


2. 2D 수평단면을 3D 위에 겹쳐도 될까요 (첨부 이미지)

"단면을 최대한 크게" 요청하신 건입니다. 방이 거의 정사각형이라 단면 크기는 세로가 정하는데,
지금 배치(3D 424 px 위 / 2D 240 px 아래)에서 단면을 키우려면 3D를 줄여야 합니다.
첨부 이미지 오른쪽처럼 2D를 3D 위에 겹치면 3D가 1.6배 커지고 단면도 키울 수 있습니다.
비율(4.5 : 4)은 그대로입니다. 왼쪽이 지금, 오른쪽이 겹친 배치입니다(둘 다 실제 화면).
