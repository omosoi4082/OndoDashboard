## 1. D. 연산 서버 인터페이스 — 수정할 부분 없습니다

D-1 ~ D-5 그대로 확정해 주셔도 됩니다. 중계 서버를 그 정의에 맞춰 구현하겠습니다.
문의하신 항목과 선택지만 아래와 같이 답변드립니다.

- **중계 서버 운영 위치**: 온도 사무실 내부망, **대시보드와 같은 PC**에서 구동합니다. 당초 명세대로
  로컬 구동이며(단일 포트 8080에서 대시보드 + `/api`) 연산 서버와 같은 내부망에 있게 됩니다.
  따라서 포트 개방·API 키·HTTPS를 따로 정할 필요가 없습니다. 연산 서버 IP만 설치 후 알려주시면
  반영하겠습니다.
- **경로**: 모드별 분리(`POST /v1/current`, `POST /v1/forecast`) 그대로 유지하겠습니다.
  한 경로(`/v1/predict`)에 `mode` 키로 통일하는 대안은 필요 없습니다.

## 2. A·B 답변 — 전부 수용해 반영합니다

A-1 ~ A-3, B-1 ~ B-10 모두 그대로 구현하겠습니다. 무리한 항목은 없습니다.
아래 세 건만 부연합니다.

- **A-1**: 원인 확인했습니다. 저희가 **12자리(`YYYYMMDDHHMM`)로 조회**하고 있어 분·초가 밀린 것이
  맞습니다. **14자리(`YYYYMMDDHHMMSS`)** 로 고쳐 반영하겠습니다.
- **B-3**: 구현 방식 한 가지만 다르게 하겠습니다 — 매시간 저장해 두는 방식 대신, 조회 시점에
  `base_date`/`base_time`에 과거 정시를 넣어 **최근 정시 4회를 직접 조회**합니다. 중계 서버를
  재시작한 직후에도 과거 3시간을 바로 복구할 수 있기 때문입니다(저장 방식은 재시작 후 3시간 동안
  '조회 실패'가 됩니다).
- **B-10**: 절감률은 **파일 값(`control.saving_pct` 38.2)을 따릅니다.** 시안의 75 %는 작성 당시의
  임시 수치로 보았습니다.

덧붙여, 그동안 값이 비어 있던 **외부환경 패널의 풍속·강수량**도 이번에 함께 채우겠습니다.
추가 API 없이 지금 호출하는 응답에서 꺼내 쓰면 되는 값이었습니다.

| 타일 | 기상청 실황 | 기상대(미세기후) |
|---|---|---|
| 풍향 | `VEC` | `WIND` (16방위 변환) |
| 풍속 | `WSD` (초단기실황) | `CURWIND` |
| 강수량 | `RN1` (초단기실황, 1시간 누적) | `RAIN` |
| 습도 | `REH` | `RH` |

## 3. 확인 요청 4건

1. **기상청 실황 결측 시 예측 모드 (B-3)** — 정시 값이 2개 이상 연속 결측이면 '기상청 실황 조회
   실패'로 처리하라고 하셨는데, **이때 예측 모드도 함께 중단됩니다.** 실측 구간 입력을 만들 수 없어
   D-2의 "실측 2.5시간 미만" 규칙에 걸려 `forecast`도 호출할 수 없기 때문입니다. 현재 모드와 예측
   모드 양쪽에 같은 실패 문구를 띄우려고 합니다.
2. **타임라인 프레임 0의 '현재' 표기 (B-7)** — 프레임 0은 D-3에 따르면 '마지막 실측 시각'(완료된
   최근 10분 정각)이라 엄밀히는 과거 시각입니다(예: 15:26에 조회하면 프레임 0은 15:20). 그래도
   시안대로 '현재'로 표기하면 되겠습니까? 아니면 '최근 실측' 같은 표현이 맞겠습니까?
3. **기상대 풍속 항목** — 센서에 `CURWIND`(현재 풍속)와 `MAXWIND`(최대 풍속)가 둘 다 있습니다.
   미세기후 패널의 풍속 타일에는 **`CURWIND`** 를 쓰려고 하는데 맞습니까?
4. **육성·비육돈방의 돼지 수와 크기 (C)** — 두 방은 전달해 주신 **도면대로 모델링해 두었습니다**
   (도면이 정확하지는 않지만 일단 도면대로 진행하라고 하신 것으로 이해했습니다). 남은 것은
   두 가지입니다.
   - **돈방별 돼지 수**: 추후 알려주신다고 하셨는데 아직 답을 받지 못했습니다. 알려주시면
     그대로 반영하겠습니다.
   - **돼지 크기**: 대략적인 비율(자돈 : 육성돈 : 비육돈)이라도 알려주시면 그에 맞추겠습니다.
     따로 기준이 없으시면 자돈 < 육성돈 < 비육돈 순으로 적절히 키워 반영하겠습니다.
