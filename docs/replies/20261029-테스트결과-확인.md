  자료에는 없다. 개발 PC에서는 사무실 연산 서버(192.168.10.91)가 보이지 않아 재현하지 못했다.

  서버 쪽에서 계산·전송 중 끊겼을 가능성. 확인 전이라 단정하지 않는다.

## 온도 측에 확인 요청한 것 (내일 답 예정)

1. **중계 서버 창 내용** — 테스트 때 띄운 `start.bat` 창의 13:55~14:20 부분(캡처나 복사). 이미 닫았으면 다음 테스트 때 닫지 않기.
2. **연산 서버 상태(10/29 13:59~14:15)** — 재시작·다른 계산/테스트 동시 실행 여부, 서버 로그의 `/v1/forecast` 오류(메모리 부족·연결 끊김 등).
3. **viz 크기 문제인지** — v1.3.3에서 `viz: true` 예측 1건이 보통 몇 초인지, 응답 크기·동시 요청 제한이 있는지.
   가능하면 `setup.bat` [2/3]에서 가시화 데이터를 **off**로 바꾸고 `test-ui.bat`을 한 번 더 돌린 결과.
4. **네트워크** — 테스트 PC와 연산 서버가 같은 사무실 망인지, 그 시간에 와이파이 끊김·공유기 재시작이 없었는지.
