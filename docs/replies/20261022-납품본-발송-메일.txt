1. 보내드리는 것

- ondo-dashboard-납품-20261022.zip (15.6 MB)
  빌드까지 끝낸 실행본입니다. 이것만 쓰시면 됩니다.

- ondo-dashboard-납품-20261022-src.zip (8.7 MB)
  소스입니다. 보관용이며, 직접 빌드하실 때는 안에 있는 install.bat 을 먼저 실행하시면 됩니다.


2. 쓰는 법 - start.bat 하나입니다

1) Node.js LTS를 설치해 주세요. 없으면 https://nodejs.org 에서 LTS 버튼으로 받아
   "다음"만 누르면 됩니다. (설치 후 PC 한 번 재시작)

2) 압축을 한글과 공백이 없는 경로에 풀어 주세요. 예: C:\ondo

3) start.bat 을 두 번 클릭하면 서버가 뜨고 브라우저가 열립니다.
   안 열리면 주소창에 http://localhost:8080 을 넣으시면 됩니다.
   검은 창은 닫지 마세요. 그 창이 서버입니다. 끝내실 때 닫으면 됩니다.

화면 값은 10분마다 자동으로 갱신됩니다.
연산 서버 주소(http://192.168.10.91:9000)는 미리 넣어 두었으니 따로 설정하실 것은 없습니다.

나머지 안내(화면 보는 법, 설정 바꾸기, 안 될 때)는 압축 안의 README.md 에 정리해 두었습니다.
Claude Code로 구동하실 경우에는 CLAUDE-구동안내.md 를 읽으라고 지정해 주시면 됩니다.


3. 기상청 서비스키 - 2028-10-09 까지입니다

지금 들어 있는 기상청 서비스키는 저희 쪽 명의로 발급받은 것이고,
활용기간이 2026-10-09 ~ 2028-10-09 입니다.
당장 하실 일은 없고, 그때까지는 그대로 쓰시면 됩니다.

다만 온도 측 명의로 키를 발급해 바꿔 두시는 편이 안전합니다.
저희 계정 사정과 무관하게 쓰실 수 있습니다. 5분이면 되고,
절차는 README.md 의 "기상청 서비스키" 항목에 적어 두었습니다. 요약하면 이렇습니다.

1) 공공데이터포털(https://www.data.go.kr)에서 "기상청_단기예보 조회서비스" 활용신청
2) 마이페이지 - 오픈API - 개발계정 에서 일반 인증키(Decoding) 복사
3) 폴더의 setup.bat 실행 후 [1/3] 기상청 서비스키 에 붙여넣기
4) start.bat 을 닫고 다시 실행

키가 만료되면 화면 왼쪽 위 기상청 값만 "-" 로 비고, 센서와 연산 서버 쪽은 그대로 동작합니다.

원인과 조치 방법까지 알려 줍니다. 결과는 점검결과.txt 로 저장됩니다.
