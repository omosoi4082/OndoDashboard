## 2. 영역별 사양

### 헤더
- 왼쪽: 비어 있다. 위치 핀 아이콘 + 동네 이름은 2026-10-26 사용자 지시로 **왼쪽 아래 외부환경 묶음**으로 내렸다(온도 추가요청 레이아웃 (2) — 3D 모델링을 더 크게 보이게). 남은 날짜·시각은 오른쪽 정렬.
- 가운데: 로고(흰색, 높이 42px).
- 오른쪽: 날짜·요일·시각 각각 별도 칸, 간격 12px, 전부 SemiBold — `2026-09-30`(16px) · `수요일`(16px) · `11:06:24`(22px, tracking 1.32px). (2026-10-10 Figma 재확인 — 날짜+요일을 한 덩어리로 합치지 않는다)
- 헤더 높이 **56px**, 좌우 여백 42px (디자인 원본 실측은 74px이었으나 2026-10-26 사용자 지시로 축소 — 로고 위 여백과 "날짜 ↔ 모드 탭" 간격이 각각 16 → 7px로 줄고, 줄어든 18px은 상세 패널 세로 공간이 된다. 3D를 더 크게 보이게). 로고 높이 42px·날짜 16px·시각 22px은 그대로.
- 헤더 아래 구분선 없음, 배경은 페이지 배경과 같음.

### 외부환경 (메인 3D 위 왼쪽 아래)
- 2026-10-26 사용자 지시로 **왼쪽 위 → 왼쪽 아래**(왼쪽 40px·아래 24px)로 내리고 묶음 전체를 **80%**로 축소했다(온도 추가요청 레이아웃 (2) — 3D 모델링을 더 크게 보이게, 상대적으로 우선순위가 낮은 정보를 다른 자리로).
  축소는 아래 실측 치수를 하나씩 0.8배 하지 않고 바깥 래퍼의 CSS transform으로 한 번에 한다(치수 표는 그대로 유지).
- 묶음 맨 위에 헤더에서 내려온 위치 표시(핀 18px + 동네 이름 15px, `.env FARM_AREA_NAME` → `GET /api/main/weather/kma`의 `areaName`)가 붙고, 그 아래 14px 간격으로 아래 두 블록이 온다. 디자인의 "제주시 아라일동 몇번지"는 자리표시 문구.
- 묶음 2개 세로 배치: 기상청 실황(3-1), 미세기후(3-2). 디자인의 "종관기상"은 쓰지 않고 데이터 명칭 "기상청 실황"을 쓴다(2026-10-09 사용자 확정).
- 제목 줄: 초록 세로줄 + 제목, 같은 줄 오른쪽에 날씨 아이콘(작게) + 기온.
- 그 아래 타일 4칸: 풍향·풍속·강수량·습도(2026-10-10 사용자 확정, 기존 습도·강수량 순서에서 변경). 풍향은 16방위 글자 + windDeg만큼 회전한 화살표(불어오는 방위). 풍속(양쪽)·기상청 강수량은 API에 아직 없어 '-'(05-open-questions #36).
- 크기(실측, 2026-10-10 Figma 재확인): 블록 폭 338, 제목 16px bold, 날씨 아이콘 18×18, 기온 18px, 타일 82×66·간격 4·모서리 4, 타일 안쪽 아이콘 18×18·아이콘-값 간격 12, 타일 값 16px·단위 14px, 블록 사이 37, 헤더 아래 18, 왼쪽 42.

#### 방 마커 (이름표 · 호버 정보 패널)
- 배치: **방 중심**에 원형 마커가 놓이고 오른쪽 8px 간격으로 글상자가 붙는다. 평소에는 이름표(알약), 호버한 방만 정보 패널로 바뀐다 — 앵커가 같아 자리가 튀지 않는다. 첫 줄(방 이름)의 세로 중앙이 원 중앙과 맞는다.
- 원형 마커: 바깥 원 20px(fill 10% + stroke 1.5px inside + drop shadow blur 20), 안쪽 점 12px.
  - 자돈방: stroke·점 `#00BD55`, 그림자 `#2AF5C0`
  - 육성·비육: stroke·점·그림자 `#888888`
- 글상자 공통: 라운드 4, 테두리 1px. 자돈방 `#2AF5C0`, 육성·비육 `#555555`.
- 이름표: 패딩 위아래 4 / 좌우 8, 글자 16px semibold. 배경 자돈방 `rgba(26,109,60,.7)` / 육성·비육 `rgba(52,52,52,.7)`.
- 호버 정보 패널: 패딩 위 4 / 좌우·아래 8. 배경 자돈방 `rgba(26,107,60,.8)` / 육성·비육 `rgba(50,50,50,.85)`.
  - 방 이름 16px semibold(이름표와 같은 크기), 이름과 정보 사이 8
  - 정보 5줄(온도·습도·환기량·NH3·CO2), 줄 간격 8, 글자 12px, 단위 8px(불투명도 50%)
  - 줄마다 값 왼쪽에 세로 막대 2×8px `#2AF5C0`(육성·비육도 같은 민트색)
- 글자색: 자돈방 `#FFFFFF`, 육성·비육 `#DBDBDB`.
- 축척 막대: **오른쪽 아래**(상세 패널 바로 왼쪽, 오른쪽·아래 여백 24px), `라벨 + 가는 선` 형태. 원래는 왼쪽 아래였는데 외부환경 묶음이 그 자리로 내려와 2026-10-26 사용자 지시로 옮겼다. 축척은 축소하지 않는다 — 막대 길이가 카메라 줌에서 계산한 실제 거리다. 값은 명세대로 카메라 줌에 따라 자동 계산(디자인의 "100m"는 예시).

### 상세 패널 (오른쪽, 가로 768px)
- 모드 탭: 둥근 컨테이너(surface) 안 4개 균등 분할. 라벨 "현재 모드 / 예측 모드 / 전문가 모드 / 제어 모드". 선택 탭은 accent로 채운 둥근 버튼.
  - 2026-10-26 사용자 지시로 UI가 3D보다 커 보이지 않게 **세로만 30% 축소**: 탭 높이 46 → 32px(모서리 16px), "분석 항목" 버튼 높이 42 → 29px. 가로(탭 182px·버튼 108px)와 글자·아이콘 크기는 그대로(온도 추가요청 레이아웃 (4)).
- 그 아래 카드(surface, 둥근 모서리) 하나에 위에서부터:
  1. "분석 항목" + 아이콘 버튼 3개 **3D 온도 / 3D 유동 / 3D 습도**(이 순서). 선택 버튼은 밝은 배경 + 밝은 테두리.
  2. 구분선
  3. (예측·전문가·제어) 모드별 컨트롤 — 예측 모드 타임라인 디자인은 아래 3장.
  4. "3D 자돈방" 제목 + 오른쪽 "● 포인트 표시" + 토글 스위치(on: 초록 점·초록 스위치, off: 회색).
     - 2026-10-26 사용자 지시로 **10% 축소**: 글자 12 → 11px, 앞 점 8 → 7px, 트랙 46×24 → **41×22**, 손잡이 16 → **14px**. 손잡이 여백은 안쪽(padding box) 기준 3px·켜짐 이동 19px로 다시 계산했다(실측: 손잡이 중심 y = 트랙 중심 y, 켜짐·꺼짐 모두 좌우 여백 3px 대칭). 시안 실측값은 46×24/16px(Figma node 374:25487).
     - "포인트 표시" 글자는 같은 날 지시로 앞 점 쪽으로 2px 당겼다 — 점↔글자 **6px**, 글자↔토글 16px(변경 없음).
  5. 3D 뷰(테두리 박스).
  6. "2D 수평단면" 제목 + 단면 박스. 색상 범례는 유지(2D 단면 디자인 미정, 추후 변경 예정).
- **패딩·간격은 전부 10px**(Tailwind 2.5) — 카드 안쪽 패딩, 섹션 사이 간격, 제목 ↔ 박스 간격, 구분선 아래 여백, 버튼 묶음 사이 간격까지 같은 값을 쓴다(2026-10-26 사용자 지시 "상세에 모든 패딩과 캡을 2.5로"). 아이콘 ↔ 글자처럼 요소 안쪽의 작은 간격, 시안에서 실측한 값(요약 카드 패딩 15/14/12, 입력 표 열 간격 12, "시간 설정" 안내 아이콘 6·4)은 예외로 그대로 둔다.
- **3D·2D 박스 크기**: 가로는 카드 안쪽을 꽉 채운다(패널 840 기준 **800px** — 2026-10-28 사용자 "상세 패널 820으로, 3D 캔버스도 비율에 맞게", 2026-10-29 840. 전에는 788 패널에 728 고정폭이라 오른쪽 여백이 왼쪽보다 20px 넓었다), **세로는 가변**(2026-10-26 사용자 승인, 온도 추가요청 레이아웃 (5) "스크롤 없이 한 화면에"). 카드에 남는 세로를 3D : 2D = **424 : 240**(이전 고정값 비율)으로 나눠 갖고, 최소 높이는 3D 280px / 2D 150px이다. 창이 그보다 작으면 예전처럼 카드 안에서 세로 스크롤이 난다.
  - 1920×945(1080 모니터에서 크롬 최대화 시 실제 viewport)에서 현재 모드 3D 435 / 2D 232px, 스크롤 없음(2026-10-26 실측).
- 스크롤 영역(3D~2D)의 스크롤바는 `.ondo-scrollbar` — 내용이 안쪽 폭을 전부 쓰므로 스크롤바가 뜨면 그 10px만큼 내용이 줄어든다(2026-10-28). 선언은 5px지만 크롬은 `scrollbar-width: thin`을 적용해 10px로 그린다.
- 모드별 컨트롤 높이도 2026-10-26 사용자 지시로 줄였다(모두 "반으로"). 가로·색·모서리는 그대로:
  - 제어 모드 최적화 토글: 높이 56 → **28**(아이콘 26 → 18px, 글자 16px 유지). 시안 실측값은 56/26. 가로는 하드코딩하지 않고 카드 폭을 따른다(패널 840 기준 800).
  - 전문가 모드 결과 화면 "필수값 수정" 줄: 50 → **25px**(버튼 348×25, 아이콘 26 → 13px, 글자 16 → 14px — 16px은 줄높이가 25px를 넘겼다). 시안 실측값은 348×50/26.
  - 전문가 모드 입력 화면 "필수값 설정" 줄: 42 → **21px**(적용·초기화·예시값 버튼 92×40 → 92×21, 글자 15 → 13px, 뒤로 가기 24 → 21px·아이콘 18). 시안 실측값은 42/40/24.
  - 전문가 모드 입력 칸: 198×36 → **198×28**(약 22% 축소, 2026-10-26 — 처음 25px(30%)로 줄였다가 사용자가 28로 다시 정했다). 글자 16px·기본 줄높이 그대로 들어간다(28 − 테두리 2 = 26 ≥ 24). 가로 198·열 간격 12·왼쪽 패딩 26(한 줄 704px 계산)은 그대로. 945 viewport에서 스크롤 없이 보이는 행이 15 → 19행(24행 중)으로 늘었다.
- 포인트 색: 디자인의 빨간 점은 표시 예시일 뿐, 명세대로 값에 따른 색.

## 3. 예측 모드 (02_예측모드_디자인_01·02)

현재 모드와 공통인 부분 외에 추가되는 것:
- "시간 설정" 줄: 오른쪽에 "ⓘ 10분 단위" 안내.
- 둥근 재생/일시정지 버튼 + 슬라이더(10분 눈금 점, 진행 구간은 파란색) + 양 끝 라벨 "00:00", "24:00".
  - 2026-10-26 사용자 지시로 **재생 컨트롤 줄 전체를 30% 축소**: 버튼 38 → 27px(아이콘 18 → 13), 트랙·채움 7 → 5px, 1시간 눈금 점 3 → 2px, 드래그 손잡이 18 → 13px(테두리 4 → 3). 버튼↔트랙 간격 16px과 말풍선은 그대로.
  - 이어서 같은 날 **트랙 가로를 20% 축소**(705 → 564px)하고 **오른쪽 끝은 그대로 둔 채 왼쪽에서 깎았다**. 줄을 오른쪽 정렬로 바꿔 재생 버튼이 트랙 왼쪽 끝에 따라붙고, 줄 왼쪽에 빈 공간이 남는다.
  - 같은 날 다시 **10% 확대(564 → 620px)**, 역시 왼쪽으로만. 늘리니 카드 안쪽 폭(748)에 꽉 차서 **버튼↔트랙 간격을 16 → 4px**로 줄였다(같은 날 "재생버튼을 라인쪽으로 조금 붙여줘"). 필요 폭 = 왼쪽 열 59 + 섹션 gap 10 + 버튼 27 + 버튼↔트랙 gap + 트랙 620 + 오른쪽 여백 = 716 + gap + 오른쪽 여백.
  - 이어 **오른쪽 열 전체를 8px 오른쪽으로** 옮겼다(오른쪽 여백 27 → **19px**. 27은 "재생 버튼 지름만큼 왼쪽으로"에서 나온 값이었고 지금은 그 유래와 무관하다).
  - 최종 실측 좌표(1920×945, 카드 안쪽 1142~1890): 재생 버튼 **1220~1247**, 트랙·라벨 줄·드래그 히트영역 **1251~1871(폭 620)**, 트랙 오른쪽 끝 ↔ 카드 안쪽 가장자리 **19px**, "↺ 초기화" 오른쪽 끝 ↔ 재생 버튼 **18.9px**. 가로 넘침 없음.
  - 2026-10-26 사용자 확인을 거쳐 **2단(2열) 배치**로 바꿨다. 왼쪽 열에 [시간 설정 + ⓘ] / [↺ 초기화], 오른쪽 열에 [재생 버튼 + 트랙] / [시각 라벨 두 개]를 쌓아 3줄 → 2줄이 됐다(섹션 높이 73 → **58px**, 실측):

    ```
    시간 설정        [▶]────────────────────
    ↺ 초기화         현재 10/26 23:00 ⓘ      10/26 23:00 / 10/27 23:00
    ```
  - 시각 라벨은 트랙과 같은 폭(564px)을 공유해 양 끝이 트랙 양 끝과 맞는다(들여쓰기 방식 폐기). 글자는 양쪽 다 **11px** — 왼쪽 "현재 …"는 12px에서 10% 축소, 오른쪽 "현재 / 마지막"은 원래 14px에서 20% 축소(그 사이 30%·10px였던 적이 있으나 11px이 최종). 줄높이는 16px로 고정해 트랙과의 간격 보정을 유지한다.
  - **ⓘ 안내 아이콘은 "현재 …" 라벨 오른쪽**에 붙는다(2026-10-26 사용자 지시로 "시간 설정" 옆에서 이동). 글자↔아이콘 6px, 아이콘 18×18, 호버 툴팁 "10분 단위"는 아이콘 오른쪽 4px·글자 **11px**(12에서 10% 축소).
  - 그 묶음은 **아래 정렬**이다(2026-10-26 사용자 지시) — 글자 상자 밑변과 아이콘 밑변이 같은 y에 놓이고(실측 둘 다 209), 18px 아이콘이 16px 줄 박스 위로 2px 삐져나오되 줄 높이와 트랙↔라벨 간격은 그대로다. baseline 정렬은 PNG 아이콘이 트랙 쪽으로 더 올라가 보여서 쓰지 않는다.
  - "↺ 초기화" 버튼은 2026-10-26 사용자 지시로 10% 축소: 글자 14 → **13px**, 아이콘 20 → **18px**(간격 4px·색·위치는 그대로).
  - ⓘ와 "현재 …"는 2026-10-26 재지시로 **가운데 정렬**이다. 다만 `info.png`는 18×18 안에 그림이 3~16행만 있어(위 3px·아래 1px 여백, 알파 스캔 실측) 상자를 맞추면 그림이 1.5px 내려 보인다 — 아이콘 상자에 `top:-1px`를 줘 보정한다(PNG는 원본이라 수정하지 않는다). 실측 글자 글리프 중심 199.5 / 아이콘 그림 중심 200.
  - 오른쪽 열(재생 버튼 + 트랙 + 라벨)은 2026-10-26 사용자 지시로 **재생 버튼 폭만큼(27px) 왼쪽으로 평행 이동**했다 — 버튼 1256~1283, 트랙·라벨 1299~1863(실측). 트랙 폭 564·버튼↔트랙 16px은 그대로이고, 트랙 오른쪽 끝과 카드 가장자리 사이에 27px 빈 공간이 남는다.
