## 2. 영역별 사양

### 헤더
- 왼쪽: 위치 핀 아이콘 + 동네 이름(기상청 격자 예보구역 이름, `.env FARM_AREA_NAME` → `GET /api/main/weather/kma`의 `areaName`). 디자인의 "제주시 아라일동 몇번지"는 자리표시 문구.
- 가운데: 로고(흰색, 높이 42px).
- 오른쪽: `2026-09-30 수요일`(15px medium) + 간격 18px + 시각 `11:06:24`(22px semibold).
- 헤더 높이 74px, 좌우 여백 42px, 위치 글자 15px (디자인 원본 실측).
- 헤더 아래 구분선 없음, 배경은 페이지 배경과 같음.

### 외부환경 (메인 3D 위 왼쪽 위)
- 묶음 2개 세로 배치: 기상청 실황(3-1), 미세기후(3-2). 디자인의 "종관기상"은 쓰지 않고 데이터 명칭 "기상청 실황"을 쓴다(2026-10-09 사용자 확정).
- 제목 줄: 초록 세로줄 + 제목, 같은 줄 오른쪽에 날씨 아이콘(작게) + 기온.
- 그 아래 타일 4칸: 풍향·풍속·습도·강수량(2026-10-09 사용자 확정). 풍향은 16방위 글자 + windDeg만큼 회전한 화살표(불어오는 방위). 풍속(양쪽)·기상청 강수량은 API에 아직 없어 '-'(05-open-questions #36).
- 크기(실측): 블록 폭 338, 제목 16px bold, 날씨 아이콘 18×18, 기온 18px, 타일 81×66·간격 5·모서리 3, 타일 아이콘 16, 타일 값 16px·단위 14px, 블록 사이 37, 헤더 아래 18, 왼쪽 42.

### 아이콘 크기(실측, 아이콘 프레임 기준)
| 위치 | 크기 |
|---|---|
| 외부환경 날씨 아이콘 | 18 |
| 외부환경 타일(풍향·풍속·습도·강수량) | 16 |
| 헤더 위치 핀 | 18 |
| 분석 항목 버튼(온도·유동·습도) | 18, 버튼 글자 15px |
| "10분 단위" 정보 아이콘 | 16 |
| 타임라인 재생 버튼 | 원형 지름 약 37 |
- 끊김 시 기존처럼 "연결 끊김" 표시.

### 메인 3D
- 모델링은 디자인 대상이 아니다(변경 없음).
- 방 이름표·마커(자돈방 초록, 육성·비육 회색)와 호버 정보 패널 디자인은 추후 전달(05-open-questions #35). 그전까지 기존 호버 패널 유지.
- 축척 막대: 왼쪽 아래, `라벨 + 가는 선` 형태. 값은 명세대로 카메라 줌에 따라 자동 계산(디자인의 "100m"는 예시).

### 상세 패널 (오른쪽, 가로 768px)
- 모드 탭: 둥근 컨테이너(surface) 안 4개 균등 분할. 라벨 "현재 모드 / 예측 모드 / 전문가 모드 / 제어 모드". 선택 탭은 accent로 채운 둥근 버튼.
- 그 아래 카드(surface, 둥근 모서리) 하나에 위에서부터:
  1. "분석 항목" + 아이콘 버튼 3개 **3D 온도 / 3D 유동 / 3D 습도**(이 순서). 선택 버튼은 밝은 배경 + 밝은 테두리.
  2. 구분선
  3. (예측·전문가·제어) 모드별 컨트롤 — 예측 모드 타임라인 디자인은 아래 3장.
  4. "3D 자돈방" 제목 + 오른쪽 "● 포인트 표시" + 토글 스위치(on: 초록 점·초록 스위치, off: 회색).
  5. 3D 뷰(테두리 박스).
  6. "2D 수평단면" 제목 + 단면 박스. 색상 범례는 유지(2D 단면 디자인 미정, 추후 변경 예정).
- 포인트 색: 디자인의 빨간 점은 표시 예시일 뿐, 명세대로 값에 따른 색.

## 3. 예측 모드 (02_예측모드_디자인_01·02)

현재 모드와 공통인 부분 외에 추가되는 것:
- "시간 설정" 줄: 오른쪽에 "ⓘ 10분 단위" 안내.
- 둥근 재생/일시정지 버튼 + 슬라이더(10분 눈금 점, 진행 구간은 파란색) + 양 끝 라벨 "00:00", "24:00".
- 재생 중 손잡이 위에 시각 말풍선.
- 카드 내용이 길어지면 카드 안에서 세로 스크롤.
- 미결 사항은 05-open-questions #37·#38.
