# 01. 화면설계 (린 버전)

> 정식 와이어프레임 툴 없이, 화면별 구성요소·인터랙션만 표로 정리.
> 레퍼런스 스크린샷(기존 2D 대시보드)의 각 요소를 3D 전환 시 어떻게 바뀌는지 매핑.

## 화면 1 — 메인 대시보드

| 레퍼런스 요소 | 전환 방식 |
|---|---|
| 상단 헤더(로고/타이틀/접속자) | HTML/Tailwind 그대로 유지 |
| 탄소 저감률 도넛 / 악취관리 카드 / AI 모니터링 표 | HTML 오버레이 (recharts 도넛 + 카드), 3D 캔버스 위에 얹지 않고 상단 고정 |
| 지능형돈사·표준형돈사 2D 아이소메트릭 그림 | 3D 씬으로 교체 (drei `<View>`로 좌우 분할 렌더링, 카메라 궤도 회전 가능) |
| 돈방별 온습도/NH3/CO2 카드 (그림 위 플로팅) | `<Html>`(drei)로 3D 좌표에 고정된 카드로 재구현 |
| 하단 외부환경/장비이상/생육환경이상 패널 | HTML/Tailwind 유지, 데이터만 API 연동 |

인터랙션:
- 돈사(또는 돈방) 클릭 → 카메라가 해당 위치로 이동 + 우측 상세 패널 open
- 지능형/표준형 탭 전환 시 분할 뷰 하이라이트 전환 (framer-motion)
- 시간 슬라이더로 시뮬레이션 프레임 이동 (기존 pig-farm-cfd-dashboard와 동일 개념)

## 화면 2 — 상세 패널 (돈방 단위)
- 등온면(볼륨) + 기류 스트림라인 3D 뷰
- 온도/습도/NH3/CO2/환기량 정보 카드
- 레이어 토글: 볼륨 표시, 기류 표시, 확산 강도 슬라이더
- 호버 시 좌표별 값 툴팁 (기존 로직 재사용)

## 화면 3 — 데이터센터 대시보드 (2개월차, 상세 TBD)
- 서버랙 배치를 축사와 동일한 패턴(외관 3D + 클릭 시 상세)으로 구성 예정
- 온도/습도 대신 서버 발열/냉각 유동 시각화로 대체
- 1개월차 완료 후 별도 화면설계 추가 예정

## 공용 컴포넌트 (2개월차 재사용 대상)
- 카메라 리그, 조명 프리셋, colormap, 볼륨/히트맵 셰이더 머티리얼
- 정보 카드, 알림 리스트, 분할화면 컨테이너
