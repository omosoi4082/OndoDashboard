# 05. 미확정 사항

여기 있는 항목은 임의로 확정하지 않는다. "현재 처리"대로 구현하고, 설정값이나 상수로 분리해 나중에 바꾸기 쉽게 둔다. 새로 생긴 미확정 사항은 아래 표에 추가한다.

| # | 항목 | 확인 대상 | 현재 처리 |

| 1 | 연산 서버 위치(같은 PC / 같은 공유기 내 다른 PC)와 포트 | 온도 | ✅ 2026-10-07 확정: 같은 공유기 내 별도 PC, 포트 9000. `COMPUTE_BASE_URL=http://<내부IP>:9000`(IP는 PC 설치 후 전달), `GET /v1/health` 헬스체크 제공 |
