  늘 보여 주고 입자 색 = 분석 항목(입자 색 토글 없앰). 등치면 없앰. 아래쪽 2D 칸을 없애고 3D를 키웠다.
  등치면·화살표 파일은 되돌릴 수 있게 남겨 두고 호출만 뺐다.
- **회신 2번**(배기구로 모으는 건 y = 0 벽만인지): 쏠림은 이미 y = 0 벽만이다(고칠 것 없음).
  다만 같은 답변의 "일정 시간 멈춰 있으면 다시 출발시키는 정도면 충분합니다"는 **샘플 HTML 규칙
  (방 안 아무 곳에서 다시 출발)을 그대로 쓰라는 뜻**이라, 밤 작업에서 되살렸다(아래).
- **회신 3번**: 전문가·제어는 목업 그대로.
- **배기구**: 입자가 원 아래 테두리에서 사라지던 것 → 배기구 앞에 오면 **원 중심으로 빨려 들어가** 사라진다.
- **범례 + 수평단면**: 3D 안 **오른쪽 아래**에 한 열로 — 범례(56×180) 아래 단면 그림, 단면 아래 끝이 제어 모드
  그래프 카드 아래 끝과 같은 줄. 범례는 하나만.
- **단면 높이 슬라이더**: "3D 자돈방" 줄 배속 앞. 0.1~2.7 m, 0.1 간격, 기본 0.5 m(모드 바꾸면 기본).
  3D에는 그 높이에 방 **바깥에만** 반투명 테(방 안은 가리지 않음), 색은 단면 그림에만. 층 사이는 위아래 층 보간
  — 그래서 기본 0.5 m는 예전(0.4 m층 그대로)과 조금 다르다(0.4로 두면 같다).
- **상세 3D 시작 카메라를 뒤로**: `CAMERA_MARGIN_FACTOR` 1.6 → 2.2(단면 테가 앞쪽에 보이게). 2.6은 천장 위로
  올라가 위쪽이 비어서 뺐다.

## 화면 확인 (집에서 볼 것)

| 어디 | 볼 것 |
|---|---|
| 상세 3D 처음 화면 | 너무 멀거나 가깝지 않은지, 앞쪽 바닥 둘레에 단면 테가 보이는지 |
| 단면 높이 슬라이더 | 끌면 테가 오르내리고 단면 그림 제목 높이·색이 바뀌는지, 테가 너무 옅거나 진하지 않은지 |
| 범례·단면 위치 | 네 모드 모두 오른쪽 아래, 제어 모드 그래프 카드와 아래 줄이 맞는지, 겹치지 않는지 |
| 입자 | 네 모드 모두 **열자마자 방 전체에 입자가 있고**, 급기구에서 새로 나와 배기구 **원 안으로** 빠지는지 |
| 멈춘 입자 | 바닥·벽에 붙은 입자가 25초쯤 뒤 사라지고 **방 안 다른 곳에서** 다시 나오는지(툭 생겨 거슬리지 않는지) |
| 배속 | 현재 모드엔 버튼이 **없고**, 예측·전문가·제어엔 있는지 |
| 배속(예측) | 3·10배에서 입자와 타임라인이 같이 빨라지는지 |
| 온도 / 습도 | 입자·포인트·단면·범례 색이 함께 바뀌는지 |

조정할 값은 모두 `apps/dashboard/src/config/constants.ts` 한 줄씩:
카메라 거리 `CAMERA_MARGIN_FACTOR`(2.2), 테 폭 `SECTION_PLANE_MARGIN_M`(0.35), 테 투명도
`SECTION_PLANE_OPACITY`(0.22), 단면 그림 폭 `SECTION_INSET_WIDTH_PX`(150), 슬라이더 범위 `SECTION_Z_MIN_M`·`SECTION_Z_MAX_M`.
