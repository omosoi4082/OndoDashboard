## 어제 밤에 한 것 (전부 커밋됨)

- **입자 기본값**: 4,000개(이 PC 실측 9,000까지 60fps), 꼬리 18, 원 크기 **화면 1.5~7 px로 자름**
  (샘플 뷰어와 같은 방식 — 월드 크기만 쓰면 확대할 때 원이 계속 커졌다), 수명 20초 뒤 급기구 재투입.
- **재생 연동**: 일시정지하면 입자도 멈춘다. 모드 진입·분석 항목(온도/유동/습도) 전환·초기화는
  **처음부터 다시 재생 + 입자도 빈 방에서 급기구부터**. 멈춘 채로 막대를 끌면 그 시각 유동장으로
  입자가 12걸음 따라온다(등치면만 바뀌고 입자가 멈춰 있던 문제).
- **칸막이**: 수평 차단 + 판 두께 5 cm 띠 + 위에서 내려오면 판 위 2 cm에 올려놓기 +
  **막힌 운동량을 위로 돌려 타고 넘기**(샘플처럼 물결 모양). `PARTITION_BLOCKS_PARTICLES=false`면 전부 끈다.
- **배기구**: 판정은 geometry의 **원(지름 0.4 m)** 으로 되돌리고, 배기구 벽에 닿은 입자는 벽면을 따라
  배기구로 모이게 했다(`OUTLET_WALL_PULL_MS = 0.4`). 60초·10배속·4,000개 실측:
  배기구로 5,085회·벽에 2,399개 → **14,522회·22개**.
- **현재 모드**에서는 배속·입자 색 버튼을 숨긴다(입자가 없는 모드라서).
- **2D 단면**: 프레임 패딩 위 2px만, Y축 숫자~단면 4px, X축 0px.
- **check.bat**: 전문가·제어가 288점일 때 "목업 파일 기준(실제 v1.3.3은 2,584점)"이라고 적는다.
- **체크리스트·화면 자동 점검**: B-3-9/10/11(입자 움직임·입자 색·배속) 추가, B-3-1/4/5/7 문구를
  자동 재생 기준으로 갱신, 현재 모드에 입자가 없다는 설명 추가. **61개 중 정상 60 / 실패 0 / 건너뜀 1**.

## 온도 측에 물어본 것 (답 오면 반영)

1. **유동일 때 2D 단면 기준** — 가(유속 유지) / 나(입자 색과 같은 값).
   나로 가면 `Detail2DSection`의 `valueField`를 입자 색(`particleColorField`)으로 바꾼다.
2. **2D 수평단면을 3D 위 오버레이로 할지** — 첨부 이미지(바탕 화면 `수평단면-오버레이-제안.png`).
   오른쪽 안은 임시 빌드로 **실제 렌더해서 찍고 되돌린 것**이다(저장소에는 없다).
   하기로 하면 `Detail2DBox`를 빼고 3D 위에 340×236 카드로 얹는다 —
   화면 점검 helpers의 `detail2dSection` 로케이터와 체크리스트 B-2-10 문구도 같이 고쳐야 한다.
