# 00. 요구사항 정의 (린 기획서)

> 정식 SI 문서가 아니라 "우리 둘(개발자·클라이언트)이 뭘 만들기로 했는지" 확인용 문서.
> 항목이 늘어나면 계약 범위(CLAUDE.md)와 항상 대조한다.

## 배경 / 목적
- (주)온도의 스마트 축사·데이터센터 공간 시뮬레이션 결과를 웹 대시보드로 시각화
- 기존 2D 아이소메트릭 대시보드 → 3D 전환, 화면 분할, 시각 이펙트 강화가 이번 작업의 핵심 차별점

## 범위 (In-scope)
- [ ] 3D 씬: 축사 3동(지능형/표준형 비교) 외관 + 클릭 시 내부 상세 씬
- [ ] 시각화 레이어: 온도/습도 등온면(볼륨), 기류 스트림라인, 유동장 히트맵
- [ ] 정보 패널: 자돈방/육성돈방/비육돈방별 온습도·NH3·CO2·환기량 카드
- [ ] 상단 요약 위젯: 탄소 저감률, 악취관리 현황, AI 모니터링 표
- [ ] 하단 위젯: 외부환경, 장비 이상, 생육환경 이상 알림 리스트
- [ ] 외부 센서 API 연동 (실시간 폴링)
- [ ] 내부 시뮬레이션 백엔드 연동 (입력 3개 → 3D 결과)
- [ ] 반응형은 데스크톱 기준 (모바일 대응 범위는 TBD — 확인 필요)

## 범위 밖 (Out-of-scope, 명시적으로 제외)
- 시뮬레이션 엔진 자체 개발 (엔지니어팀 담당)
- 센서 하드웨어/설치
- 2개월차 데이터센터 화면 상세 스펙 (1개월차 완료 후 별도 확정)

## 일정
- 계약기간: 2026-10-01 ~ 2026-11-30
- 1개월차: 축사 대시보드
- 2개월차: 데이터센터 대시보드 (축사에서 만든 공용 컴포넌트 재사용)
