## 집에서 할 순서

1. `git pull` 후 `git switch flow-particles`
2. `npm install` → `npm run typecheck && npm test` — 처음 돌리는 것이라 오류가 날 수 있다
3. `flowParticles.ts` 단위 테스트 추가(아직 없음): 보간 꼭짓점 값 일치, 격자 밖 자르기, 배기구 도달 시 재생성, 수명 재생성
4. `npm run dev` → 예측 모드 → 유동: 입자가 급기구 아래로 내려와 배기구 벽(y=0) 쪽으로 흐르는지, 온도/습도 전환·범례, 타임라인 재생 중 끊김 없는지
5. 화면 보고 `FLOW_PARTICLE_*` 조정(배속·크기·개수)
6. `npm run lint`, `npm run test:ui` — 유동 화살표를 보던 점검 항목이 있으면 입자로 고친다

## 확인할 점

- 목 유속장은 급기구 아래로 내려가 배기구 쪽(−y)으로 쏠린다. 바닥에서도 아래로 향해 입자가 바닥에 붙음 → 멈춤 1.5초 뒤 재생성으로 처리.
- Canvas가 `logarithmicDepthBuffer: true`라 직접 셰이더 대신 내장 PointsMaterial·LineBasicMaterial(RGBA 정점색)을 썼다. 투명도가 안 먹으면 여기부터 본다.
- 성능: 입자 2,500 × 꼬리 10 = 매 프레임 보간 약 2.8만 회(CPU). 느리면 개수부터 줄인다.
