# 온도 스마트 축사(돈사) 시뮬레이션 대시보드 — 사용 안내

제주 돈사의 센서·기상 데이터를 받아 자돈방 내부 환경을 3D로 보여주는 대시보드입니다.
**이 PC 한 대에서 화면과 중계 서버가 함께 돌아갑니다.** 별도 서버나 데이터베이스는 필요하지 않습니다.

> 처음 받으셨다면 아래 **"처음 한 번만"** → **"쓰는 법"** 순서로 보시면 됩니다.
> 기상청 서비스키는 **기한이 있으니** 아래 "기상청 서비스키" 항목을 꼭 확인해 주세요.

---

## 처음 한 번만

### 1. Node.js 설치

이 프로그램은 Node.js가 있어야 돌아갑니다. 이미 설치돼 있으면 건너뛰세요.

1. <https://nodejs.org> 접속
2. **LTS** 라고 적힌 버튼으로 내려받기
3. 내려받은 파일을 실행하고 **계속 "다음"** 만 누르면 됩니다 (바꿀 설정 없음)
4. 설치가 끝나면 **컴퓨터를 한 번 다시 시작**해 주세요

> 확인하려면: 시작 메뉴에서 `cmd` 실행 → `node -v` 입력 → `v20.x.x` 같은 게 나오면 정상입니다.

### 2. 압축 풀기

받으신 압축 파일을 **한글·공백이 없는 경로**에 푸세요. 예: `C:\ondo\`

> `바탕 화면`이나 `다운로드` 폴더에서 바로 실행하면 경로 때문에 실패하는 경우가 있습니다.

폴더 안에 `start.bat`, `check.bat`, `setup.bat` 이 보이면 제대로 풀린 것입니다.

## 쓰는 법

**`start.bat`** 을 두 번 클릭하세요. 평소에 쓰실 것은 이 파일 하나입니다.

- 검은 창이 뜨고 잠시 뒤 **브라우저가 자동으로 열립니다**
- 안 열리면 브라우저에 직접 입력: **<http://localhost:8080>**
- **검은 창은 닫지 마세요.** 그 창이 서버입니다. 닫으면 화면도 멈춥니다
- 끝낼 때는 검은 창을 닫으면 됩니다
- 같은 네트워크의 다른 PC에서 볼 때는 서버 PC의 주소로 접속합니다 (예: `http://192.168.0.10:8080` —
  주소는 검은 창에 찍혀 있습니다)

화면 값은 **10분마다 자동으로 갱신**됩니다. 새로고침하지 않아도 됩니다.

## 화면 보는 법

| 자리 | 보이는 것 |
|---|---|
| **왼쪽 위 — 외부환경** | 기상청 실황(온도, 풍향·풍속·강수량·습도)과 농장 기상대 센서의 미세기후 |
| **가운데 — 돈사 3D** | 자돈방·육성돈방·비육돈방. 방에 마우스를 올리면 온도·습도·환기량·NH3·CO2 카드가 뜹니다.<br>마우스 왼쪽 버튼으로 끌면 회전, 휠로 확대·축소 |
| **오른쪽 — 상세 패널** | **자돈방** 내부를 네 가지 모드로 봅니다(아래) |

상세 패널 네 모드:

- **현재 모드** — 지금 자돈방 내부 상태. 3D 점 125개와 아래쪽 2D 수평단면
- **예측 모드** — 앞으로의 변화. ▶ 를 누르면 시간순으로 재생됩니다
- **전문가 모드** — 0시~23시의 온도·습도·환기량을 직접 넣고(24줄) **적용**을 누르면 그 조건의 결과를 봅니다.
  표가 비어 있을 때 나오는 **예시값** 버튼을 누르면 72칸이 한 번에 채워집니다
- **제어 모드** — 에너지 최적화와 환경 최적화를 비교합니다. 절감률·팬 전력량·최고 온도 요약이 함께 나옵니다

공통 조작: **분석 항목**(온도 / 유동 / 습도)으로 색 기준을 바꾸고, **포인트 표시** 토글로 점을 끄거나 켭니다.
오른쪽 색 막대가 값과 색의 대응입니다.

> 육성돈방·비육돈방은 회색이고 클릭되지 않습니다. 상세 데이터는 자돈방만 제공합니다.

## 기상청 서비스키 — {{KMA_EXPIRY}} 까지만 쓸 수 있습니다

지금 들어 있는 기상청 서비스키는 **개발 측 명의로 발급받은 키**입니다.
활용 마감일이 **{{KMA_EXPIRY}}** 이고, 그 날짜가 지나면 화면 왼쪽 위 **기상청 실황 값이 `-` 로 빕니다.**
센서 서버와 연산 서버 쪽은 영향을 받지 않습니다.

**지금 당장 하실 일은 없습니다.** 마감일까지는 그대로 쓰시면 됩니다.
다만 그 전에 **온도 측 명의로 키를 발급해 바꿔 주시는 편이 안전합니다**(개발 측 계정 사정과
무관하게 쓰실 수 있습니다). 아래 순서로 5분이면 됩니다.

1. 공공데이터포털 <https://www.data.go.kr> 에 회원가입·로그인
2. 검색창에 **`기상청_단기예보 조회서비스`** 를 넣고, 그 서비스 화면에서 **활용신청**
   (개발계정은 신청하면 바로 승인됩니다)
3. **마이페이지 → 오픈API → 개발계정** → 신청한 서비스를 클릭 →
   **일반 인증키(Decoding)** 값을 복사합니다
   > **Encoding이 아니라 Decoding** 값입니다. `%2F` 같은 글자가 섞여 있으면 Encoding 쪽이니 다른 값을 쓰세요.
4. 폴더에서 **`setup.bat`** 을 두 번 클릭 → `[1/3] 기상청 서비스키` 에 붙여넣고 엔터
   (뒤의 항목은 엔터만 치면 지금 값이 그대로 유지됩니다)
5. 검은 창(`start.bat`)을 닫고 **다시 실행**하면 반영됩니다

바꾼 뒤 **`check.bat`** 을 눌러 `[4/7] 기상청` 이 `✅` 로 나오면 끝입니다.

> 새로 발급한 키에도 **활용 마감일**이 있습니다. 위 3번 화면에서 종료일을 확인하시고,
> 만료 전에 같은 화면에서 **연장신청**을 해 두세요. 하루 조회 한도도 그 화면에 함께 나옵니다
> (이 프로그램은 10분에 한 번 조회해 한도에 여유가 있습니다).

## 설정 바꾸기 — `setup.bat`

**`setup.bat`** 을 두 번 클릭하면 세 가지를 차례로 묻습니다. **엔터만 치면 지금 값이 유지됩니다.**

| | 항목 | 언제 바꾸나 |
|---|---|---|
| 1 | 기상청 서비스키 | 위 "기상청 서비스키" 참고 |
| 2 | 연산 서버 모드·주소 | 연산 서버 PC가 바뀌거나 주소가 바뀌었을 때 |
| 3 | 센서 서버 모드·주소 | 센서 서버 주소가 바뀌었을 때 |

바꾼 뒤에는 **검은 창을 닫고 `start.bat` 을 다시 실행**해야 반영됩니다.
`.env` 파일을 직접 열어 고치지 마시고 이 파일을 쓰세요(바꾸기 전 자동으로 백업됩니다).

## 안 될 때

**먼저 `check.bat` 을 눌러 보세요.** 센서 서버·기상청·연산 서버 연결을 하나씩 확인해
`✅` / `❌` 로 보여주고, `❌` 에는 **원인과 조치 방법이 바로 아래 같이 나옵니다.**
결과는 `점검결과.txt` 파일로도 저장됩니다.

| 증상 | 해결 |
|---|---|
| `start.bat` 을 눌러도 창이 깜빡이고 사라짐 | Node.js가 설치되지 않았습니다. "처음 한 번만 1."을 해 주세요 |
| 브라우저에 아무것도 안 나옴 | 검은 창이 켜져 있는지, 주소가 `http://localhost:8080` 인지 확인 |
| 왼쪽 위 외부환경이 전부 `-` | `check.bat` → `[4/7] 기상청` 확인. 인터넷 연결, **그리고 서비스키 마감일**을 보세요 |
| 방 하나만 "끊김" | 그 방 센서 장비 상태를 확인해 주세요 (프로그램 문제가 아닙니다) |
| 상세 패널에만 "예측 서버 연결 안 됨" | 연산 서버 PC가 켜져 있는지, 같은 네트워크인지 확인 |
| "연산 서버가 이 PC의 접속을 허용하지 않습니다" | 이 PC의 내부 IP(`cmd` → `ipconfig` → IPv4 주소)를 연산 서버 허용 목록에 넣어야 합니다 |
| 그래도 안 됨 | `check.bat` 실행 후 생기는 **`점검결과.txt`** 를 개발 측에 보내 주세요 |

## 이런 동작은 정상입니다

- **전문가 모드 결과가 입력값과 상관없이 같게 나옴** — 연산 서버가 아직 전문가 모드 계산을
  제공하지 않아 예시 응답을 보여주는 단계입니다
- **제어 모드에서 에너지/환경을 바꿔도 결과가 같음** — 같은 이유입니다
- **타임라인 중간에 "입력 조건이 검증 범위를 벗어났습니다(참고용)."** — 오류가 아닙니다.
  연산 결과가 그 구간을 모델 검증 범위 밖으로 표시한 것을 그대로 보여 줍니다
- **2D 수평단면이 한 가지 색으로 보임** — 그 높이(바닥에서 0.5 m)의 온도가 고르면 그렇게 보입니다.
  축 눈금·칸막이 선·색 막대가 보이면 정상입니다
- **육성·비육돈방에 돼지가 없고 회색임** — 상세 데이터는 자돈방만 제공합니다
- **육성돈방·비육돈방 호버 카드만 있고 클릭이 안 됨** — 설계대로입니다

## 지원 환경

- **Windows 10 / 11**
- **Chrome 또는 Edge 최신 버전** (Internet Explorer는 지원하지 않습니다)
- 화면 해상도 **1920 × 1080 기준** — 모바일·태블릿은 지원하지 않습니다
- 센서 서버·연산 서버와 **같은 네트워크**에 있어야 합니다
- 기상청 조회를 위해 **인터넷 연결**이 필요합니다
